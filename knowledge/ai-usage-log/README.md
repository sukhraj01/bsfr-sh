# AI Usage Log

Supporting material for the academic-integrity record: verbatim prompts and an
AI-generated vs. human-written attribution per session.

For this project that record lives inside each `sessions/*.md` file — the Prompts and
What was done sections — rather than in a parallel tree, so there is one file per session
to write and one to read.

Use this directory for anything that does not fit a session file: exported transcripts,
screenshots, or an end-of-project consolidated attribution table for the report.
